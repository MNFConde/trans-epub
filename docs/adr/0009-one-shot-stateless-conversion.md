# 0009. 一次性全量转换，无缓存无增量

- 状态：accepted
- 日期：2026-10-10（2026-10-24 回填为 ADR）
- 相关：requirements.md（使用模式与失败策略）

## 背景

个人文档规模下重跑成本低；缓存/增量会引入失效判断、状态管理与一致性问题，显著提高复杂度，且与"服务化时任务可重放"的诉求相性差。

## 决策

一次性全量转换，无缓存无增量，重跑即重来。失败策略配套：批量中单页/单项失败不中止，记 warning 继续，结尾汇总报告。

## 后果

- 大部头书重复转换全量耗时（可接受）。
- 换来无状态内核：测试简单、golden 可复现、服务侧天然幂等。
